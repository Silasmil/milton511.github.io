🚀 Milton Silas — 2026 Cybersecurity Learning Journey

This is a public, living roadmap documenting my focused journey in cybersecurity throughout 2026. The emphasis is on depth, hands-on practice, and proof of work, not credentials alone.

Background (Context, Not Excuses)

  • Completed secondary school at 17
  • No traditional college pathway
  • Skills built through online programs, labs, mentorship, and disciplined self-study
  • Transitioned into a professional cybersecurity role within one year of focused learning
  • 2026 focus: API Security, Web Application Security, Practical Defense

🎯 Core Theme for 2026

“Secure the interfaces that power modern systems.”

APIs are the backbone of cloud, mobile, fintech, and AI platforms. My objective is to become exceptionally strong in API security testing, design flaws, and exploitation paths, backed by solid security fundamentals.

🧠 Knowledge Pillars

Q1 2026 — Foundations

Objective: Eliminate weak fundamentals.

  • Networking & protocols (HTTP/1.1, HTTP/2, TLS, DNS)
  • Linux internals & command-line fluency
  • Security principles: CIA, threat modeling, risk
  • Governance, Risk & Compliance exposure (ISC2 CC track & events)

Proof of work:

  • Structured notes published on GitHub
  • Documented labs and walkthroughs
  • Teaching others to reinforce mastery

Q2 2026 — Web & API Security Core

Objective: Become highly effective with modern web stacks.

  • OWASP Top 10 (Web & API)
  • REST vs GraphQL security issues
  • Authentication & authorization failures
  • IDOR, BOLA/BFLA, mass assignment
  • Rate limiting & business logic abuse

Primary tools:

  • Burp Suite
  • Postman
  • curl & scripting
  • JWT tooling

Proof of work:

  • Completed PortSwigger labs (Apprentice → Practitioner)
  • Sanitized public write-ups
  • Custom API security testing checklists

Q3 2026 — API Exploitation & Advanced Testing

Objective: Go beyond automated scanning.

  • Manual API abuse chains
  • Broken object-level authorization
  • OAuth 2.0 & JWT attack patterns
  • Web cache poisoning & request smuggling (where applicable)
  • API security in microservices

Proof of work:

  • Personal vulnerable API lab projects
  • Recreated real-world vulnerabilities (safe demos only)
  • GitHub repositories with detailed explanations

Q4 2026 — Defensive Thinking & Blue Awareness

Objective: Think like a defender who understands attackers.

  • API logging & monitoring concepts
  • Detection ideas for API abuse
  • Secure API design patterns
  • Developer collaboration & DevSecOps mindset

🧪 Hands-On Platforms

  • PortSwigger Web Security Academy
  • Self-built vulnerable APIs
  • Simulated production-like environments
  • Teaching labs to validate understanding

📜 Certifications & Recognition

  • ISC2 Candidate
  • ISC2 Certified in Cybersecurity (CC) track
  • Continuous learning through ISC2 community & events
  • Certifications treated as validation, not the goal

🧩 How I Learn

  • Learn → Break → Fix → Teach
  • Daily lab practice (even short sessions)
  • Document everything
  • One domain at a time: API Security first

🛡️ 2026 Identity

Cybersecurity Analyst (Practice-Focused)
API & Web Application Security
Self-Taught • Disciplined • Lab-Driven
